# 2026-09-08

## BulkCopy 支持/实现盘点
- 入口: `ExpressionContextExtension`(src/LightORM/Extension) `Db.Ado.BulkCopy<T>(IEnumerable<T>)`(实体→DataTable, 过滤 IsNotMapped/IsAggregated/IsNavigate, bool 列存 object + adapter.HandleBooleanValueForBulkCopy) + `BulkCopy(DataTable)` → `IDatabaseProvider.BulkCopy(DataTable)`。
- 实现: SqlServer(SqlBulkCopy+KeepIdentity, bool→"true"/"false")、MySql(MySqlConnector MySqlBulkCopy, 要求连接串含 allowloadlocalinfile, 并执行 SET GLOBAL local_infile=1)、Oracle(OracleBulkCopy UseInternalTransaction)、Dameng(DmBulkCopy) 已实现; KingbaseES(NotImplementedException)、PostgreSQL/Sqlite(NotSupportedException) 未实现。
- 一致性差异: 事务模型不一(Oracle 走内部事务, 其余显式 BeginTransaction); bool 转换默认基类 "1"/"0"(仅 SqlServer override 为 "true"/"false"); 均自行建连/关闭绕过 AOP 拦截器; BulkCopyTimeout 固定 120。
- 测试: LightORMTest 基类仅 1 用例(删表 + BulkCopy 20 条 User, 不校验结果), SqlServer/MySql/Oracle/Dameng/PostgreSQL 有派生; KingbaseES/Sqlite 无测试; PostgreSQL 有测试类但 Provider 抛 NotSupportedException(README 亦注明不支持)。
- README: "SqlServer/MySql/Oracle/Dameng 支持, PostgreSQL/SQLite 不支持", 未提及 KingbaseES。
